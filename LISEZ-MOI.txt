MISE A JOUR VEILLE-ILI - SCENARIO DEIR EZ-ZOR

Ce dossier contient uniquement les fichiers a ajouter ou remplacer dans votre depot GitHub.

1. Ouvrez votre depot GitHub simulation-veille.
2. Cliquez sur Add file, puis Upload files.
3. Deposez tout le contenu de ce dossier a la racine du depot.
4. Lorsque GitHub demande confirmation, acceptez le remplacement de app.js, index.html, eleve.html et styles.css.
5. Validez avec Commit changes, puis attendez une ou deux minutes le redeploiement GitHub Pages.

Ne supprimez pas les anciens dossiers assets : les autres scenarios les utilisent encore.

Le nouveau scenario s'appelle :
RedLand : convoi francais fictif dans la region de Deir ez-Zor

Il comprend un fil de 690 publications simulees, 13 nouveaux visuels, des comptes officiels, medias locaux, temoins, ONG, fact-checkers, bots et relais d'influence. Toutes les positions, unites, routes et heures operationnelles sont fictives.
