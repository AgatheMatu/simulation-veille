MISE A JOUR RAPIDE VEILLE-ILI

Ce dossier contient seulement les fichiers modifies et les 10 nouveaux avatars.
Il evite de renvoyer les centaines d'images deja presentes sur GitHub.

1. Ouvrir le depot GitHub simulation-veille.
2. Cliquer sur Add file, puis Upload files.
3. Deposer TOUT LE CONTENU de ce dossier a la racine du depot :
   index.html, eleve.html, app.js, styles.css, README.md, .nojekyll et assets.
4. Valider avec Commit changes.
5. Attendre le voyant vert github-pages, puis actualiser la page avec Ctrl+F5.

IMPORTANT

- Ne supprimez pas le dossier assets/evidence deja en ligne.
- Les fichiers de meme nom doivent remplacer les anciennes versions.
- Le dossier assets/avatars ajoute les nouveaux comptes sans effacer les anciens.
- Le compte @cema_france est utilisable uniquement depuis la page enseignant.
